This is a **sample post** so you can see how an essay looks on the site. It is safe to delete: add a Markdown file to `src/content/blog/`, fill in the frontmatter at the top, write below it, commit, and it publishes with its own URL, SEO tags, and a place in the sitemap and RSS feed.

## How a post is structured

Every post is a Markdown file with a small block of frontmatter at the top. The `title` and `description` drive the page title, meta description, and the social share card. `pubDate` sets the date and ordering. Set `draft: true` while a piece is unfinished and it stays off the live site.

### What Markdown gives you

Standard Markdown renders the way you would expect:

- Bulleted lists for enumerating points
- **Bold** and *italic* for emphasis
- Inline `code` and fenced code blocks
- Links, like [VirtuNx](https://virtunx.com/)

> A pull quote sets a line apart when it deserves the weight. Use it sparingly.

Numbered lists work for sequences:

1. Write the Markdown file
2. Commit it
3. It deploys and appears in the sitemap and RSS feed
